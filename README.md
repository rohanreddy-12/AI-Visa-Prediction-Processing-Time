# AI-Enabled Visa Status Prediction and Processing Time Estimator

## 📌 Project Overview
Visa applicants often face long waiting times and uncertainty regarding the progress of their applications. This project aims to develop a predictive analytics system that estimates visa processing times based on historical data. By analyzing past H-1B application records—including applicant country, processing office, prevailing wage, and seasonal variations—this system provides data-driven estimates to improve transparency and the applicant experience.

## 🎯 Key Outcomes
* **Data-Driven Estimates:** Predict approximate processing times for visa applications using regression modeling.
* **Trend Analysis:** Identify seasonal, regional, and workload-based patterns in visa processing delays.
* **User-Friendly Tool (Upcoming):** A web-based estimator tool for applicants to check expected timelines.
* **Improved Transparency:** Reduce uncertainty with accurate, data-backed predictions.

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Data Manipulation:** `pandas`, `numpy`
* **Data Visualization:** `matplotlib`, `seaborn`


## 📂 Repository Structure
* `visa.py` - The core data engineering pipeline. Cleans raw data, handles missing values, and outputs the processed datasets.
* `visa3.py` - The Exploratory Data Analysis (EDA) script. Reads the cleaned data to generate statistical visualizations and correlation heatmaps.
* `h1b_data_cleaned_for_eda.csv` - The intermediate, human-readable dataset generated by `visa.py` specifically for `visa3.py`.
* `h1b_data_preprocessed_final.csv` - The fully encoded (One-Hot) dataset prepared for Machine Learning model training.
* `outputs/` - Directory containing the generated EDA charts and visualizations (screenshots).
