How predictions work:

This estimator uses an XGBoost regression model trained on millions of historical H-1B/PERM visa processing records. Every form field is encoded using the same LabelEncoder used during training — so all fields affect the prediction.

→Employer characteristics (state, H-1B dependency, violation history)
→Wage level and prevailing wage relative to SOC benchmark
→Case status and application year seasonality
→Job title, SOC code, work location, and employment type

Use ⚡ Autofill to instantly populate all fields with a random realistic scenario.
